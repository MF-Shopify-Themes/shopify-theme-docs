### 🛠️ General Troubleshooting Guide

Here are the solutions to the most common issues you might encounter while setting up or customizing your Shopify theme. 

### ❌ 1. Theme Upload Fails

* **Issue:** You see an error saying *"Zip file is invalid"* or *"Missing template"* during upload.
* **Solution:** Ensure you are uploading the raw, compressed .zip theme file. Do not unzip the folder on your computer before uploading. If you downloaded a package that contains documentation and the theme, extract that main package first to find the actual theme .zip file inside.

### 💾 2. Changes Not Saving in the Editor

* **Issue:** You click "Save" in the Shopify Theme Editor, but your changes disappear or don't show up.
* **Solution:** This is usually a temporary Shopify server delay or a browser cache issue. Try clearing your browser cache (Ctrl + F5 or Cmd + Shift + R) or open the editor in an Incognito/Private window.

### 📱 3. Layout Looks Broken on Mobile

* **Issue:** Images look blurry, or text overlaps on mobile screens.
* **Solution:** Make sure your uploaded images follow the recommended aspect ratios specified in the section settings. If you added custom HTML or CSS blocks, ensure they use responsive design rules (like percentages instead of fixed pixel widths).

### 🧩 4. App Sections Disappeared

* **Issue:** After updating the theme, your third-party app widgets (reviews, upsells, etc.) are gone.
* **Solution:** When you install a new theme version, you need to go to **Theme Settings** > **App embeds** in the Shopify Editor and re-enable the toggle switches for your active apps.
