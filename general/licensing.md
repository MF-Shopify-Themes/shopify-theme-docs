# 📜 Theme licensing and usage

By purchasing and downloading a theme from this organization, you agree to the following standard licensing terms: 

* **Single-Store License:** Each theme purchase grants you a non-exclusive license to use the theme on a **single live Shopify store**.
* **Development Stores:** You are allowed to install the theme on development or staging environments associated with that specific store for testing purposes.
*   **Modifications & Derivations:** You are allowed to modify the theme's code solely to customize it for your own live store. You are strictly prohibited from using this theme, or any part of its code, as a framework, base, or template to create derivative themes for resale, redistribution, or public distribution.
* **Support Limits:** Standard support covers theme-specific features and bugs. Custom code modifications or third-party app integration issues fall outside the scope of free theme support.
